# otp-core

Geração e verificação HOTP (RFC 4226) e TOTP (RFC 6238) com janelas de
ressincronia. Só crypto do Node, zero dependências.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes com o apêndice RFC 4226 completo
npm run demo
```

Somente suítes SHA-1; segredos nunca registrados. MIT — veja `LICENSE`.
